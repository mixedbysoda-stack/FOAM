# FOAM

Reverb plugin by Carbonated Audio. VST3, AU and AAX for macOS (Apple Silicon and Intel, macOS 11 or later).

This repository hosts the installer downloads only.

- Product page and purchase: https://carbonatedaudio.com
- Download the latest installer from the Releases page.
- FOAM needs a license key to run. Paste the key from your receipt email when the plugin opens. One key covers 3 machines and works offline after activation.
